# TOUFIQ — Personal Portfolio 🌐

A clean, modern, and interactive personal portfolio website designed for an **AI Researcher & Developer**. Built with a warm, minimalist aesthetic and fluid animations powered by GSAP.

---

## ✨ Features

- **🎬 Dynamic Splash Screen** — Minimalist "WELCOME" screen with animated typography that transitions into the main portfolio.
- **🎨 Warm Aesthetic Theme** — Carefully curated color palette featuring warm cream, deep near-black, and rich maroon accents.
- **👤 Interactive Profile Card** — Portrait showcase with hover zoom, floating status badge, offset accent frame, and ambient motion.
- **⚡ Zero Build Steps** — Fully modular vanilla architecture (HTML5, CSS3, modern JavaScript). Runs instantly without npm builds.
- **📱 Fully Responsive** — Optimized for desktops, tablets, and mobile screens.

---

## 🛠️ Tech Stack

- **Markup & Layout:** HTML5, CSS3 (Modern Flexbox & Grid, CSS Variables)
- **Typography:** Google Fonts ([Montserrat](https://fonts.google.com/specimen/Montserrat))
- **Animations:** [GSAP (GreenSock Animation Platform)](https://greensock.com/gsap/)
- **Icons:** Lightweight inline SVG icons

## 🚀 Getting Started

### Option 1: Direct Open (Easiest)
Simply double-click `index.html` to view it in your favorite browser.

### Option 2: Local Server
To run a local development server:

```bash
# Using Python
python3 -m http.server 5173

# Or using Node (if installed)
npx serve
```

Then open `http://localhost:5173` in your browser.
